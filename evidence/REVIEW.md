## Known limitations

1. Test butuh Docker karena memakai Testcontainers. Di mesin tanpa Docker, API tetap bisa dijalankan dengan Postgres lokal, tetapi `dotnet test` gagal saat start container.
2. Self-approval tidak bisa dipicu lewat seed bawaan: Alice bukan approver, user lain tidak punya manager, dan System Owner yang meminta akses aplikasinya sendiri sudah ditolak saat create. Aturan ini tetap dijaga di service (`SELF_APPROVAL_NOT_ALLOWED`), di `CanDecide`, dan di CHECK `ck_access_requests_manager_not_requester` serta `ck_access_requests_owner_not_requester`. Belum ada test HTTP yang memicu 403 `SELF_APPROVAL_NOT_ALLOWED` secara langsung.
3. Skenario unauthorized approval dan duplicate submit tidak bisa didemokan lewat UI karena tombolnya disembunyikan dan key dibuat otomatis. Demo memakai `backendApproval.http`.
4. Hanya ada satu policy (`v1`). Registry dan kolom `policy_version` sudah disiapkan untuk Phase 2, tetapi belum diuji dengan dua policy aktif berganti.
